# 历史剪贴板（Windows 快捷贴图版）

自动记录复制过的文字和图片，保存在本机。支持拖曳框选、无边框图片贴屏和带柔和光感的深色界面。

## 直接运行

打开 `dist\历史剪贴板-快捷版.exe`。

**如果旧版正在运行，先右键系统托盘里的剪贴板图标 → 退出，再打开快捷版。** 软件只允许一个实例运行，直接打开新版会呼出旧版窗口。

新版放在原来的 `dist` 目录中，会继续读取旁边的 `data` 历史数据。迁移或备份时，复制整个软件目录及其 `data` 文件夹。

## 操作方式

- **单击卡片**：查看完整文字或图片，不会自动切换窗口。
- **双击卡片 / Enter / 预览中的“粘贴”按钮**：复制并返回打开历史前的窗口粘贴。
- **Ctrl+C / “复制”按钮**：复制选中的记录；在搜索框或文字预览中选中文字时，Ctrl+C 复制所选文字。
- **↑ / ↓**：浏览记录。
- **Ctrl+F**：搜索文字；支持按原样搜索百分号、下划线和反斜杠。
- **Ctrl+Alt+V**：从其他软件呼出历史。
- **Q+1**：先按住 Q，再按主键盘的 1（或开启 NumLock 的小键盘 1），直接将当前剪贴板图片贴屏。无需打开历史窗口；长按只触发一次。这个组合预留给贴图：打字时若 Q 尚未松开就按 1，也会触发。
- **Esc**：依次取消多选、退出多选、清除搜索，最后隐藏窗口。
- **右键卡片**：复制、粘贴、置顶、删除。
- **框选**：按住左键从卡片或列表空白处拖动，自动进入多选；在顶部或底部边缘拖动可自动滚动。默认替换选择，按 Ctrl 拖动追加选择，反向拖动也支持。单击仍用于预览或设置中的快速粘贴。
- **多选**：“全选已加载”只选当前加载的记录。Ctrl+A 在多选模式中也可全选，搜索框保留文字全选行为。
- **记录中 / 已暂停**：直接暂停或恢复记录，与托盘菜单同步。
- **更多 → 清空全部历史**：确认后删除全部记录，包括置顶内容。

偏好原来的快速操作时，可在 **设置 → 操作方式 → 单击卡片直接粘贴** 中开启。

## 图片贴屏

选中图片后点击预览中的 **贴到屏幕**，或者右键图片卡片 → **贴到屏幕**。

截图或复制图片后，**按住 Q 再按 1** 也可直接贴屏；从资源管理器复制单张图片文件同样支持。图片出现在鼠标所在的屏幕中央，主窗口隐藏或暂停历史记录时也可使用。托盘菜单中的“贴屏当前图片（Q+1）”提供同样的操作。剪贴板无图片时显示提示。Q 单独输入及其他组合会正常回放，快捷键不同时搭配 Ctrl、Alt、Shift 或 Win；释放 Q 后可再次使用。

- 图片作为独立浮窗显示，默认置顶。主窗口隐藏后仍保留，可同时展示多张图片。
- 贴图只显示原始图片和右上角透明底的半透明叉号，四周有淡淡的外侧光晕；无边框、工具栏或填充底板。透明图片的透明区域保持透明。
- 按住图片拖动移动；滚轮或 + / - 缩放。
- 双击图片、按 0 或右键菜单恢复原始大小（大图以屏幕可容纳的尺寸为限）。
- 右键菜单可切换置顶、缩放和复制图片；Ctrl+C 也可复制原图，复制内容不包含关闭按钮或光晕。
- Esc 或右上角关闭按钮关闭当前贴图；从托盘彻底退出程序时关闭全部贴图。
- 已打开的贴图保存在内存中，即使原历史记录被清理也能继续展示。贴图位置不会跨程序重启保存。

## 功能与数据

- 全部、文字、图片、置顶四种筛选；置顶记录优先显示，自动清理时保留。
- 完整文字预览可以滚动和选取，新增文字保留原始缩进与前后空白；旧记录之前丢失的空白无法补回。
- 图片在预览区域内保持比例，随窗口大小缩放。
- 新记录出现时，保留当前预览、多选状态和滚动位置。
- 分批加载历史；窗口大小及预览区域宽度会在关闭窗口时保存。
- 保留天数和容量上限可以设置；超出后清理最旧的非置顶内容。
- 关闭窗口后继续在后台记录；彻底退出请使用托盘菜单。
- 所有历史数据均保存在软件旁的 `data` 文件夹内。

## 自动粘贴没反应

目标窗口已关闭、Windows 阻止切换前台、修饰键尚未松开，或目标软件以管理员身份运行时，自动粘贴可能失败。程序会保留已复制的内容并提示手动 Ctrl+V。图片文件失效时不会粘贴剪贴板中的旧内容。

## 开发与打包

```powershell
pip install -r requirements.txt
python main.py
```

运行 `build.bat`，或在依赖已安装后执行：

```powershell
python make_icon.py
python -m PyInstaller --onefile --windowed --noconfirm --name "历史剪贴板-快捷版" --icon icon.png main.py
```

验证：

```powershell
python smoke_test.py
python ui_smoke_test.py
python hotkey_test.py
```

界面测试使用独立临时数据库和离屏剪贴板，不修改真实历史。示例界面截图保存在 `preview`，截图中的内容是测试样例。
